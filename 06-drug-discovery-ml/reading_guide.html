英文术语对照表

读英文论文时随时查，按你的4个步骤分组

第1步：数据

吸收、分布、代谢、排泄、毒性
ADMET (Absorption, Distribution, Metabolism, Excretion, Toxicity)
药物在体内的五个关键药代动力学性质。TDC数据库里ADME类数据集就是这些。
定量构效关系
QSAR (Quantitative Structure-Activity Relationship)
用数学模型建立分子结构和生物活性之间的关系。你正在做的就是QSAR建模。
简化分子线性输入规范
SMILES (Simplified Molecular Input Line Entry System)
用文本字符串表示分子结构。如阿司匹林: CC(=O)Oc1ccccc1C(=O)O
类药性
Drug-likeness
分子是否具备成为药物的特征。Lipinski规则是判断类药性的一种方法。

第2步：特征工程

分子描述符
Molecular Descriptor
人工计算的分子性质数值（MW, LogP, TPSA等）。你之前用的7个就是描述符。
分子指纹
Molecular Fingerprint
将分子结构编码成二进制向量。每个bit表示某个子结构是否存在。
扩展连接性指纹 / Morgan指纹
ECFP (Extended Connectivity Fingerprint) / Morgan Fingerprint
最常见的圆形指纹。以每个原子为中心，看周围radius层（通常2层）的子结构。RDKit中用GetMorganFingerprintAsBitVect生成。
特征工程 / 分子表示
Feature Engineering / Molecular Representation
将分子转化为计算机可读的数字向量。这步决定模型性能上限。
稀疏向量
Sparse Vector
大部分元素为0的向量。2048维Morgan指纹通常只有几十个1，其余全0，就是稀疏的。

第3步：模型

随机森林
Random Forest (RF)
建多棵决策树投票。你之前用的n_estimators=200就是建200棵树。
支持向量机
SVM (Support Vector Machine)
找一个最优超平面将不同类别分开。在高维稀疏数据（如指纹）上效果好。
梯度提升树
XGBoost / Gradient Boosting
逐步训练，每棵新树修正上一棵的错误。业界比赛常用。
交叉验证
Cross-Validation (CV)
将数据分成K份，轮流用K-1份训练、1份验证，取平均。你之前用cv=10。
超参数
Hyperparameter
模型训练前需要人为设定的参数（如n_estimators、max_depth）。不是从数据学出来的。

第4步：验证

训练集 / 测试集
Training Set / Test Set
训练集用于学习参数，测试集用于评估泛化能力。模型不能见过测试集数据。
随机切分
Random Split
train_test_split的默认方式。可能导致训练集和测试集有结构相似的分子，分数虚高。
骨架切分
Scaffold Split
按Murcko骨架分组，训练集和测试集的骨架不重叠。更接近真实场景。
Murcko骨架
Murcko Scaffold / Bemis-Murcko Scaffold
剥离分子侧链后的核心环系结构。用于scaffold split的分组依据。
泛化能力
Generalization
模型对未见过数据的预测能力。训练集分数高≠泛化好。
过拟合
Overfitting
模型"记住"了训练数据而非学到规律，在新数据上表现差。
数据泄露
Data Leakage
训练集和测试集有信息重叠（如相似分子），导致分数虚高。随机切分常有这个问题。

评估指标

准确率
Accuracy
预测正确的比例。分类任务常用。
精确率 / 召回率 / F1
Precision / Recall / F1-score
分类的多维度评估。precision=预测为正中真正为正的比例；recall=真正为正中被预测为正的比例。
均方误差
MSE (Mean Squared Error)
预测值和真实值差的平方取平均。回归任务指标，越小越好。
决定系数
R² (Coefficient of Determination)
回归模型解释的方差比例。范围0-1，越接近1越好。
接收者操作特征曲线
ROC-AUC (Area Under the Receiver Operating Characteristic Curve)
分类模型在不同阈值下的整体表现。AUC=1完美，0.5随机猜。

读英文论文的策略

1. 不要从头读到尾。 先读Abstract（摘要）和Conclusion（结论），判断这篇和你需要的相关不。相关再继续。
2. 跳过数学公式。 第一遍不需要看懂每个公式。先理解"这步在干什么、为什么需要"，公式细节后面用到了再回来看。
3. 重点看图表。 综述论文的核心信息都在表里——"什么方法用于什么任务、效果如何"。表格比文字信息密度高得多。
4. 用翻译工具辅助。 推荐用DeepL（deepl.com）或Google Translate，整段翻译对比着看。遇到术语查上面的对照表。不要逐句翻译，先看中文综述建立概念，再回英文论文看细节。
5. 阅读顺序建议。 先读中文的"药学学报2024"那篇建立框架 → 再读CSDN博客理解分子表示演变 → 然后用术语对照表辅助读英文的Carracedo 2021那篇。
