1.4 Caco-2 是什么（药学背景）

Caco-2 渗透性实验
Caco-2 细胞来源于人结肠腺癌，在培养皿中会长成类似小肠上皮的细胞单层。

实验：把药物加在细胞层一侧（AP侧），测另一侧（BL侧）的药物浓度，算出渗透系数 Papp。

意义：预测口服药物的肠道吸收能力。渗透性差 = 吃了吸收不了。
Papp (cm/s)渗透性口服吸收预期
> 10×10⁻⁶高> 90% 吸收
1~10×10⁻⁶中中等
< 1×10⁻⁶低< 20% 吸收

2特征工程

特征工程 = 把分子翻译成计算机能懂的数字向量。

这一步是整条流水线的关键——特征决定模型性能的上限。模型再强，如果特征没包含关键信息，预测就不可能准。

2.1 两种特征化方式

方式A：分子描述符

人工设计的宏观指标，每个都有明确化学含义。

维度：通常7~200维

优点：可解释性强，你知道每个数字代表什么

缺点：信息压缩太多，丢失大量结构细节

例：[345.2, 3.1, 62.5, 2, 1, 3, 0.42]

方式B：Morgan指纹

自动扫描分子结构片段，编码成二进制向量。

维度：通常1024~2048维

优点：保留更多结构信息，捕捉细节

缺点：不可解释（你不知道每个bit对应什么）

例：[0,1,0,0,1,0,...,0] 共2048位

2.2 描述符计算（你已经会的）

from rdkit import Chem
from rdkit.Chem import Descriptors
import numpy as np

def calc_descriptors(smiles_list):
    """计算7个常用分子描述符"""
    features = []
    for smi in smiles_list:
        mol = Chem.MolFromSmiles(smi)
        if mol is None:
            continue
        mw = Descriptors.MolWt(mol)
        logp = Descriptors.MolLogP(mol)
        hba = Descriptors.NumHAcceptors(mol)
        hbd = Descriptors.NumHDonors(mol)
        tpsa = Descriptors.TPSA(mol)
        rotatable = Descriptors.NumRotatableBonds(mol)
        fsp3 = Descriptors.FractionCSP3(mol)
        features.append([mw, logp, hba, hbd, tpsa, rotatable, fsp3])
    return np.array(features)

# 使用
X_desc = calc_descriptors(df['Drug'].values)
y = df['Y'].values
print(f'描述符矩阵形状: {X_desc.shape}')  # (907, 7)

2.3 Morgan指纹计算（新知识）

Morgan指纹原理

Morgan指纹又叫ECFP（Extended Connectivity Fingerprint，扩展连接性指纹）。它的工作方式：

  1. 以分子中每个原子为中心
  2. 看它周围 radius 层邻居的结构（radius=2 就是看2层）
  3. 每个独特的子结构对应2048个位置中的一个
  4. 有这个子结构就标1，没有就标0
打个比方：描述符像一个人的"身高体重血压"（7个宏观指标），指纹像一张2048像素的全身照（微观细节全保留）。

代码实现

from rdkit import Chem
from rdkit.Chem import AllChem
from rdkit.DataStructs import ConvertToNumpyArray
import numpy as np

def calc_morgan_fingerprint(smiles_list, radius=2, n_bits=2048):
    """计算Morgan指纹"""
    fps = []
    for smi in smiles_list:
        mol = Chem.MolFromSmiles(smi)
        if mol is None:
            continue
        # 生成指纹对象
        fp = AllChem.GetMorganFingerprintAsBitVect(mol, radius=radius, nBits=n_bits)
        # 转成numpy数组（sklearn只能吃numpy数组）
        fp_array = np.zeros((n_bits,), dtype=np.int8)
        ConvertToNumpyArray(fp, fp_array)
        fps.append(fp_array)
    return np.array(fps)

# 使用
X_fp = calc_morgan_fingerprint(df['Drug'].values)
print(f'指纹矩阵形状: {X_fp.shape}')  # (907, 2048)
注意：GetMorganFingerprintAsBitVect 返回的不是 numpy 数组，而是 RDKit 自己的 ExplicitBitVect 对象。必须用 ConvertToNumpyArray 转成 numpy 数组才能喂给 sklearn。

参数说明

参数常用值含义
radius2以每个原子为中心看几层邻居。2=ECFP4，3=ECFP6
nBits2048指纹长度。1024或2048最常用，太长容易稀疏，太短容易碰撞

什么是"碰撞"？

2048个位置对应不了所有可能的子结构（分子子结构的种类是无限的）。多个不同子结构可能被哈希到同一个位置——这叫碰撞。nBits越大，碰撞概率越低，但向量越稀疏。2048是实践中效果和效率的平衡点。

2.4 检查特征的稀疏度

# 看看指纹有多稀疏
density = X_fp.mean()  # 1的比例
print(f'指纹密度: {density:.4f} (平均每个分子有 {density*2048:.1f} 个1)')
# 通常只有2-3%的位置是1，剩下都是0 → 很稀疏
稀疏数据（Sparse Data）
大部分元素是0的向量叫稀疏向量。Morgan指纹通常只有2-3%的位置是1，就是稀疏的。

对模型的影响：稀疏数据上，SVM（支持向量机）通常比RandomForest效果好。因为决策树在高维稀疏数据上容易过拟合。

3多模型对比训练

用不同特征 + 不同模型组合，看哪种搭配效果最好。

3.1 三个模型对比

模型一句话原理适合的特征
RandomForest 建200棵决策树投票，每棵树学不同的数据子集 描述符（低维、少量特征）
SVM 找一个最优超平面把数据分开（回归叫SVR） 指纹（高维、稀疏数据）
XGBoost 梯度提升，每棵新树修正上一棵树的错误 两者都行，业界比赛常用

3.3 评估指标说明

指标含义范围越好
R²模型解释了多少方差负无穷 ~ 1越大越好，1最好
MSE预测值和真实值差的平方平均0 ~ 正无穷越小越好
RMSEMSE开根号，和Y同单位0 ~ 正无穷越小越好
R² 为负数是什么意思？
R² 可以是负数。这说明模型还不如"直接猜均值"的效果。出现负的 R² 通常意味着：
1. 特征和标签几乎没关系
2. 模型超参数设得不好
3. 数据量太少

4验证方式

4.1 随机切分的问题

train_test_split 是随机切分的。但药物分子经常有相似的骨架（scaffold）——随机切分时，训练集和测试集可能含有结构极其相似的分子。

结果就是：模型只要"记住"了骨架就能答对测试集，分数虚高。

随机切分 Random Split

训练集和测试集可能有相同骨架

分数虚高

模拟场景：给你一个类似的分子，你能不能预测

骨架切分 Scaffold Split

训练集和测试集的骨架不重叠

更真实

模拟场景：给你一个全新骨架类型的分子，你能不能预测

4.2 Murcko骨架是什么

Murcko骨架 = 把分子的侧链都去掉，剩下的核心环系结构。

举个例子（概念示意）：

分子A: 苯环-OH-O-CH2-CH3   → 骨架: 苯环
分子B: 苯环-NH2             → 骨架: 苯环
分子C: 萘环-COOH            → 骨架: 萘环

分子A和B骨架相同，C不同。scaffold split会把A和B都放训练集（或都放测试集），不会分开。

4.3 Scaffold Split 代码实现

RDKit 可以提取 Murcko 骨架：

from rdkit import Chem
from rdkit.Chem.Scaffolds import MurckoScaffold
import numpy as np

def get_murcko_scaffold(smi):
    """获取分子的Murcko骨架SMILES"""
    mol = Chem.MolFromSmiles(smi)
    if mol is None:
        return None
    scaffold = MurckoScaffold.MurckoScaffoldSmiles(mol=mol)
    return scaffold

# 计算所有分子的骨架
scaffolds = [get_murcko_scaffold(smi) for smi in df['Drug']]
print(f'唯一骨架数量: {len(set(scaffolds))}')

按骨架分组切分：

def scaffold_split(smiles_list, y, test_size=0.2, seed=42):
    """按骨架切分数据集"""
    # 1. 给每个分子算骨架
    scaffolds = {}
    for i, smi in enumerate(smiles_list):
        mol = Chem.MolFromSmiles(smi)
        if mol is None:
            continue
        scaffold = MurckoScaffold.MurckoScaffoldSmiles(mol=mol)
        if scaffold not in scaffolds:
            scaffolds[scaffold] = []
        scaffolds[scaffold].append(i)
    
    # 2. 按骨架的分子数量从多到少排序
    scaffold_list = sorted(scaffolds.values(), key=len, reverse=True)
    
    # 3. 依次分配骨架，直到测试集达到目标大小
    n_total = len(smiles_list)
    n_test_target = int(n_total * test_size)
    
    train_idx = []
    test_idx = []
    np.random.seed(seed)
    
    # 打乱骨架顺序（避免大骨架都在一边）
    np.random.shuffle(scaffold_list)
    
    for scaffold_indices in scaffold_list:
        if len(test_idx) < n_test_target:
            test_idx.extend(scaffold_indices)
        else:
            train_idx.extend(scaffold_indices)
    
    return np.array(train_idx), np.array(test_idx)

# 使用
train_idx, test_idx = scaffold_split(df['Drug'].values, y, test_size=0.2)

X_train = X_fp[train_idx]
X_test = X_fp[test_idx]
y_train = y[train_idx]
y_test = y[test_idx]

print(f'训练集: {len(train_idx)}, 测试集: {len(test_idx)}')

4.4 两种切分方式对比

对比实验：同一个模型（指纹+SVR），分别用随机切分和骨架切分训练，看测试集R²的差距。

# 随机切分
X_tr_rand, X_te_rand, y_tr_rand, y_te_rand = train_test_split(
    X_fp, y, test_size=0.2, random_state=42
)
model_rand = SVR(kernel='rbf')
model_rand.fit(X_tr_rand, y_tr_rand)
r2_rand = r2_score(y_te_rand, model_rand.predict(X_te_rand))
print(f'随机切分 R²: {r2_rand:.3f}')

# 骨架切分
model_scaf = SVR(kernel='rbf')
model_scaf.fit(X_fp[train_idx], y[train_idx])
r2_scaf = r2_score(y[test_idx], model_scaf.predict(X_fp[test_idx]))
print(f'骨架切分 R²: {r2_scaf:.3f}')

print(f'下降幅度: {(r2_rand - r2_scaf):.3f}')
为什么 scaffold split 分数一定更低？
因为任务变难了——模型需要泛化到从未见过的骨架类型。

随机切分更像"做过的题换个数字"，骨架切分更像"全新题型"。

真实药物研发中，你遇到的新分子骨架往往和训练数据不同，所以 scaffold split 的分数更接近真实表现。

# ---- 第4步：scaffold split验证 ----
from rdkit.Chem.Scaffolds import MurckoScaffold
from sklearn.metrics import r2_score

def scaffold_split(smiles_list, test_size=0.2, seed=42):
    scaffolds = {}
    for i, smi in enumerate(smiles_list):
        mol = Chem.MolFromSmiles(smi)
        if mol is None: continue
        scf = MurckoScaffold.MurckoScaffoldSmiles(mol=mol)
        if scf not in scaffolds:
            scaffolds[scf] = []
        scaffolds[scf].append(i)
    
    scaffold_list = sorted(scaffolds.values(), key=len, reverse=True)
    np.random.seed(seed)
    np.random.shuffle(scaffold_list)
    
    n_test_target = int(len(smiles_list) * test_size)
    train_idx, test_idx = [], []
    for indices in scaffold_list:
        if len(test_idx) < n_test_target:
            test_idx.extend(indices)
        else:
            train_idx.extend(indices)
    return np.array(train_idx), np.array(test_idx)

train_idx, test_idx = scaffold_split(df['Drug'].values, test_size=0.2)
