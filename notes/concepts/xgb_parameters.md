# XGBoost 参数详解

> 创建：2026.09.28
> 更新：2026.09.28

## 一句话总结

XGBoost 的参数不是孤立的，它们互相影响。调参要有顺序，从影响最大的开始，一层层往下调。

---

## 参数全景图

按影响大小排序：

```
影响最大： n_estimators, learning_rate, max_depth
影响中：  subsample, colsample_bytree, min_child_weight
影响小：  reg_alpha, reg_lambda, gamma
```

---

## 第一梯队（最常调，影响最大）

### n_estimators — 树的数量

| 项目 | 说明 |
|------|------|
| 全称 | n（数量）+ estimators（估计器/树） |
| 默认值 | 100 |
| 调大 | 模型更复杂，可能更准，但容易过拟合，也更慢 |
| 调小 | 模型简单，快，但可能欠拟合 |

**实际怎么用**：配合早停一起用。设一个比较大的数（如 1000），让早停自己决定用多少棵树。

---

### learning_rate — 学习率

| 项目 | 说明 |
|------|------|
| 全称 | learning（学习） + rate（速率） |
| 默认值 | 0.3 |
| 调大 | 每步走得远，学得快，但容易"走过头"，不稳定 |
| 调小 | 每步走得近，学得慢，但更稳，更不容易过拟合 |

**和 n_estimators 的关系**：
- 学习率小 → 需要更多棵树（n_estimators 要大）
- 学习率大 → 需要的树少

**经验搭配**：
- `learning_rate=0.1` + `n_estimators=500`（常用）
- `learning_rate=0.05` + `n_estimators=1000`（更稳）
- `learning_rate=0.01` + `n_estimators=5000`（最稳，最慢）

---

### max_depth — 每棵树的最大深度

| 项目 | 说明 |
|------|------|
| 全称 | max（最大） + depth（深度） |
| 默认值 | 6 |
| 调大 | 树更深更复杂，能学更细的模式，但容易过拟合 |
| 调小 | 树浅，简单，不容易过拟合，但可能学不到复杂规律 |

**经验值**：
- 数据少/特征少 → 3~5
- 数据多/特征多 → 6~10
- 分子指纹 2048 位 → 6~8 比较常用

---

## 第二梯队（控制过拟合，中等影响）

### subsample — 每棵树随机抽多少样本

| 项目 | 说明 |
|------|------|
| 全称 | sub（子） + sample（样本） |
| 默认值 | 1.0（全部用） |
| 调小（如 0.8） | 每棵树只用 80% 的样本，增加随机性，防过拟合 |
| 调大 → 1.0 | 每棵树用全部样本，更准但更容易过拟合 |

为什么随机抽样能防过拟合？每棵树看到的数据都不一样，学到的东西就有差异，组合起来就不容易"集体犯错"。

**经验值**：0.7~0.9 之间。0.8 是常用值。

---

### colsample_bytree — 每棵树随机抽多少特征

| 项目 | 说明 |
|------|------|
| 全称 | col（列=特征） + sample + by tree（每棵树） |
| 默认值 | 1.0（全部用） |
| 调小（如 0.8） | 每棵树只用 80% 的特征，增加随机性，防过拟合 |
| 调大 → 1.0 | 全部特征都用，更准但更容易过拟合 |

和 `subsample` 是一对搭档：一个随机抽样本，一个随机抽特征。两个一起用，随机性更强，防过拟合效果更好。

**经验值**：0.6~0.9。特征很多时（如 2048 位指纹），可以调小一点（0.6~0.8）。

---

### min_child_weight — 叶子节点最小权重

| 项目 | 说明 |
|------|------|
| 全称 | min（最小） + child（子节点） + weight（权重） |
| 默认值 | 1 |
| 调大 | 叶子节点需要更多样本才会分裂，树更简单，防过拟合 |
| 调小 → 1 | 叶子节点样本少也能分裂，树更复杂，容易过拟合 |

简单说：一个叶子节点至少要有多少样本，才会继续往下分裂。如果样本太少，就不再分了。

数据量大可以调大一点（如 5~10），数据小就用默认 1。

---

## 第三梯队（正则化，影响较小）

### reg_alpha — L1 正则

| 项目 | 说明 |
|------|------|
| 全称 | reg（正则化 regular） + alpha（α） |
| 默认值 | 0（不启用） |
| 调大 | 惩罚大，特征变少（稀疏化），模型更简单 |

L1 正则的作用是让不重要的特征权重变成 0，相当于自动做特征选择。特征特别多时（如 2048 位指纹）可以调一下。

---

### reg_lambda — L2 正则

| 项目 | 说明 |
|------|------|
| 全称 | reg + lambda（λ） |
| 默认值 | 1（默认就有） |
| 调大 | 惩罚大，模型更保守，防过拟合 |
| 调小 → 0 | 不惩罚，模型更激进 |

L2 正则让所有特征的权重都变小，但不会变成 0。是最常用的正则化方式。

默认值 1 就挺好，一般不用动。过拟合严重时可以调到 2~5。

---

### gamma — 分裂最小增益

| 项目 | 说明 |
|------|------|
| 全称 | gamma（γ，希腊字母） |
| 默认值 | 0（不限制） |
| 调大 | 分裂需要更大的收益才会分，树更简单 |
| 调小 → 0 | 只要有收益就分，树更复杂 |

简单说：分裂一次至少要带来多少好处，不然不分。也是防过拟合的一种手段。

---

## 参数之间的互相关系

参数不是孤立的，牵一发而动全身。

### 强耦合对

#### learning_rate 和 n_estimators

```
学习率大 → 每步走得远 → 需要的树少
学习率小 → 每步走得近 → 需要的树多
```

单独调其中一个没意义，必须配合着调。

---

#### max_depth 和正则化参数

```
max_depth 大 → 树很复杂 → 需要更强的正则化
max_depth 小 → 树简单 → 正则化可以弱一点
```

树越深，越需要"刹车"（正则化）来控制。

---

#### subsample 和 colsample_bytree

两个都是"增加随机性防过拟合"的，效果是**叠加**的。两个都调得很小，随机性太强，每棵树质量下降，组合起来也不准了。

经验：两个加起来一般不低于 1.2（如 0.6 + 0.6 = 1.2）。

---

#### max_depth 和 min_child_weight

都控制树的复杂度，有替代关系：

- 限制深度（max_depth 小）→ 树长高到一定程度就不让长了
- 限制叶子最小样本（min_child_weight 大）→ 叶子太小就不分了

效果类似，但角度不同。数据量大的时候，`min_child_weight` 更合理；数据量小的时候，`max_depth` 更直接。

---

## 调参顺序

从上往下调，调完一个再调下一个。不要一次调三个，你根本不知道是哪个起了作用。

```
第1步：learning_rate + n_estimators   ← 先调好这两个（配合早停）
  ↓
第2步：max_depth                      ← 确定模型复杂度的上限
  ↓
第3步：subsample / colsample_bytree   ← 加随机性防过拟合
  ↓
第4步：min_child_weight               ← 再调叶子最小样本
  ↓
第5步：reg_lambda / gamma             ← 最后碰正则化
```

---

## 判断欠拟合还是过拟合

调参之前，先搞清楚是哪种情况：

| 现象 | 类型 | 怎么调 |
|------|------|--------|
| 训练集差、测试集也差 | 欠拟合 | 增大模型：树更多、更深、学习率更大 |
| 训练集很好、测试集差 | 过拟合 | 减小模型 / 加随机性 / 加强正则 |
| 训练集和测试集都还可以 | 刚刚好 | 微调优化 |

---

## 生活类比

调参就像调收音机：

- **学习率** = 调台步长（大步转还是小步转）
- **树的数量** = 转多少下
- **树深度** = 收音机的音质档位（越高级功能越多，但也越容易出杂音）
- **随机抽样** = 加一点杂音干扰，反而让你听得更清楚（防止钻牛角尖）

## 起步参数建议（分子指纹场景）

```python
XGBRegressor(
    n_estimators=1000,          # 设大点，让早停决定
    learning_rate=0.05,         # 稳一点
    max_depth=6,                # 默认值
    subsample=0.8,              # 80% 样本
    colsample_bytree=0.8,       # 80% 特征
    early_stopping_rounds=50,   # 早停
    random_state=42,
    n_jobs=-1,
)
```

这是一个比较稳妥的起点，先跑通看效果，再根据是欠拟合还是过拟合来调。
