# 早停机制 (Early Stopping)

> 创建：2026.09.28
> 更新：2026.09.28

## 一句话总结

如果验证集上的性能连续 N 轮都没有变好，就停止训练。最终用性能最好的那一轮的模型。

---

## 核心概念

### 为什么需要早停

XGBoost 是一棵树一棵树往上加的。树越多，模型越复杂，但也越容易过拟合：

- **树太少** → 欠拟合（学不到东西）
- **树适中** → 刚刚好
- **树太多** → 过拟合（记住了训练集的噪音，换数据就不准）

```
性能
  ↑
  │         ●
  │       /   \
  │     /       \  ← 过拟合了，测试集性能开始下降
  │   /
  │ /
  └──────────────→ 树的数量
      最优点
```

早停就是帮你找到那个"最优点"，到了就停，不让模型继续学过头。

### 判断逻辑

以 `early_stopping_rounds=50` 为例：

#### 第1步：记录最佳成绩

每加一棵树，就在验证集上算一次误差。记住"目前最好的成绩"是多少，出现在第几轮。

```
第1轮: 验证RMSE = 0.83  ← 目前最好（best = 0.83，第1轮）
第2轮: 验证RMSE = 0.80  ← 更好了，更新
第3轮: 验证RMSE = 0.77  ← 更好了，更新
...
```

#### 第2步：每轮检查"连续多少轮没进步"

每一轮都算：当前轮 - 最佳轮 = 已经连续多少轮没进步。

```
假设第550轮是最好的（RMSE = 0.43021）

第551轮: 0.43030  ← 比最好差 → 没进步 1 轮
第552轮: 0.43025  ← 比最好差 → 没进步 2 轮
...
第600轮: 0.43042  ← 比最好差 → 没进步 50 轮 → 停！
```

只要没超过历史最佳，就算"没进步"，计数加 1。中间偶尔回升一下也没用，**必须超过历史最佳才能清零计数**。

#### 第3步：最终用哪棵树

不是用最后那棵，是用"最好成绩那一轮"的模型。XGBoost 会自动回退到最优的那一轮。

最佳轮次存在 `best_iteration` 属性里。

---

## 关键参数

| 参数 | 含义 | 默认值 | 说明 |
|------|------|--------|------|
| `early_stopping_rounds` | 连续多少轮没提升就停 | 无（不启用） | 常用值：30~100 |
| `min_delta` | 至少提升多少才算"真的变好" | 0 | 用来过滤噪音波动 |

### early_stopping_rounds

值越大 → 等得越久 → 越不容易误停，但可能过拟合多一点。

经验：**50 是常用值**。数据少、噪音大可以设大一点（如 100）；数据多、信号稳可以设小一点（如 20~30）。

### min_delta

为什么需要这个？因为验证集误差有**波动**（噪音），不是光滑下降的。`min_delta` 用来过滤掉这些小波动——只有提升超过这个阈值，才算"真的进步"。

**怎么设：**

1. **大多数情况用 0** 就行
2. **看数据尺度**：标签范围的千分之一到万分之一
   - 标签范围 0~1 → 0.0001 ~ 0.001
   - 标签范围 -7~-3 → 0.001 ~ 0.01
   - 标签范围 0~100 → 0.01 ~ 0.1
3. **看验证集曲线的波动幅度**：设得比噪音幅度略大一点

## 容易搞错的细节

### 1. 早停只看验证集，不看训练集

训练集误差永远下降（树越多越好），看训练集永远不会停。早停必须用验证集。

### 2. 多个验证集时看最后一个

`eval_set=[(A,yA), (B,yB)]`，早停看 B（最后一个）。

### 3. 必须严格变好才算

默认 `min_delta=0`，平了都不算，必须好一丢丢。

### 4. 最终模型不是最后一轮的

是最佳那一轮的。如果早停在第 600 轮，最佳在第 550 轮，实际用的是第 550 轮的模型。

### 5. `best_iteration` 属性不一定有

- 没设早停 → 属性不存在
- 设了早停但没触发 → 属性存在但为 `None`
- 设了早停且触发了 → 有具体数值

所以访问前要用 `hasattr()` 检查一下。

## 生活类比

想象你在刷题备考：

- 计划刷 1000 道题
- 每刷 1 道题就做一套模拟卷
- 连续 50 套卷子分数没提高 → 不刷了（再刷就是死记硬背了）
- 最后用分数最高那个水平的自己去考试

早停就是自动帮你判断"刷多少道题刚刚好"。
