## 2026.09.28 — 分子指纹是近似，不是真相

分子指纹把三维的、动态的、有电子云的真实分子，压扁成一串 0 和 1。丢的信息很多（三维结构、手性、顺反异构…），但关键是：丢的信息对当前任务影响有多大？如果 80% 的信息够用，那 20% 的失真可以接受。

这不只是分子指纹的问题——所有模型都是这样。牛顿力学不是"真的"（相对论更接近），但造桥造火箭够用了。原子模型从实心球到行星模型到电子云，每次都是"更接近"，但没人敢说"就是真相"。

**模型的价值不在于"真不真"，而在于"准不准"。** 只要在特定的问题上预测得准，它就是有用的。

这也是为什么药物发现里有那么多种分子表示方法（描述符、指纹、药效团、对接、GNN…）——没有一种是"最真实的"，每种都是在某些场景下够用。

## 2026.09.28 — 分工不同，设计目的不同

不同的数据结构（list vs Index）、不同的函数设计（一体化 vs 分离职责），没有绝对的"好坏"，只有"适不适合"。

- list 是通用容器，什么都能装
- Index 是专门存索引的，查找快

- 一体化封装适合固定流程，用起来方便
- 分离职责适合多变的场景，灵活可组合

**本质区别在于分工不同、设计目的不同。** 理解了"这个东西是为什么场景设计的"，就理解了它的特点，而不用死记硬背。

这个思路可以推广到几乎所有技术概念——不要问"哪个更好"，要问"哪个更适合我现在的场景"。

## 2026.09.28 — 边学边写日志，比事后回忆强太多

学一点、想一点、写一点，比"先看完一整章再做笔记"有效得多。

原因：
1. 想法是转瞬即逝的，触发点过去了就写不出来了
2. 边学边写等于立刻检验自己懂没懂，避免"我懂了"的幻觉
3. 记录真实的学习路径（绕弯路、踩坑、顿悟），比事后整理的"正确答案式"笔记更有价值

费曼学习法的自然形态就是这样——学一点、跟自己讲一遍、写下来。

## 2026.09.28 — 刨根问底不是浪费时间

搞清楚每个概念"为什么这么设计""和那个有什么关系""本质区别是什么"，比多跑通十个脚本还值钱。

跑通脚本谁都行，但能把每个概念的关系都理清楚的人不多。到后期拼的不是记住多少函数名，而是脑子里有没有清晰的知识框架。

"不问清楚就不痛快"这种性格，做技术是优势。

## 2026.09.29 — 与 AI 协作的方法论

### 核心问题

用 AI 生成代码，自己不写，能学会吗？会虚浮吗？能力能积累吗？

### 角色定位

- **你是架构师**：定方向、做决策、把关结果
- **AI 是执行者**：写模板代码、跑流程、查资料、排查报错

### 代码分类

| 类型 | 举例 | 谁来写 |
|------|------|--------|
| 模板代码 | 文件读写、API调用、画图框架 | AI写，你能看懂 |
| 核心逻辑 | 阈值定多少、用什么特征、选什么模型、怎么评估 | 你定，AI执行 |
| 语言基础 | if/for/函数定义/pandas数据处理 | 你必须会写 |

### 能力分层

| 能力 | 要求 | 检验标准 |
|------|------|---------|
| 能看懂 | 每行代码知道在干什么 | 给你代码你能逐行讲 |
| 能改 | 能改参数、改路径、改逻辑 | 换个靶点你知道改哪里 |
| 能判断 | 结果对不对你有感觉 | 准确率95%你能说清是好还是有问题 |
| 能默写 | 不做要求 | 查文档写出来就算会 |

### 阶段性演进

```
第1个项目（EGFR）→ AI写，你读，学结构
第2个项目（COX-2）→ 你写核心逻辑，AI写模板
第3个项目（DPP-4）→ 你写大部分，AI只查bug
第4个项目开始 → 你独立写，AI只当字典
```

### 防错意识

AI会犯三类错，你必须防：
1. **逻辑错误**：代码跑通但结果错了 → 靠"能判断"防
2. **参数不当**：参数不合理 → 靠"能看懂"防
3. **知识错误**：用错指标用错方法 → 靠"能判断"防

最后一道防线永远是你，不是AI。

### 不可量化能力的积累

架构设计、模型选择、特征选择、结果判断——这些能力靠四件事：

1. **每个决策都问"为什么"**：AI每次做决策时告诉你理由，记住的是理由不是结论
2. **同一件事做两遍对比**：用指纹 vs 用描述符，对比结果差多少、为什么
3. **犯错然后记住**：设错阈值 → 看到结果变差 → 理解阈值的影响
4. **读别人的代码和论文**：跟自己的做法对比，谁的对

### 检验方法

每做完一个项目，问自己三个问题：
1. 关掉AI，我能从零写一个同类项目吗？
2. 项目再大三倍，我知道怎么扩展结构吗？
3. 换个靶点，我知道改哪里吗？

### 函数名记不住不要紧

知道做什么、知道结果对不对，这就是会。函数名记不住是肌肉记忆的事，不是能力问题。查文档写出来和默写出来，没有本质区别。做得多了自然就记住了。

### 虚浮感的本质

觉得虚浮不是因为没用AI，是因为看得多、跑得少。跑代码、报错、自己改——这个过程重复十几次，虚浮感就消失了。
